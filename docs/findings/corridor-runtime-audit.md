# Shared-corridor runtime audit — where the same street gets two clocks

> **Lineage:** generated by the corridor-audit tooling in the analysis home
> (`corridor_audit.md` / `.csv`). Method: on every street segment shared by
> two or more routes, compare each pair's scheduled running time across the
> segment; flag pairs whose medians diverge. **Edges audited: 61,526 ·
> comparable pairs: 8,636 · flagged (delta ≥ 3.0 min): 277.** Vintage:
> 2026-09-04. Promoted to the findings lane 2026-09-11.
>
> **What this adds:** when two routes ride the identical street between the
> identical stops, they should book nearly identical time. Where they
> don't, one schedule is lying — and a rider planning a transfer off the
> slower route's timetable is being mis-served by paper.

specials legitimately run different times on shared streets; pair-level
context in the CSV separates them.
